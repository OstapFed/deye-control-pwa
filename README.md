# Deye Control PWA — мобільне демо

Україномовний демонстраційний PWA-додаток для домашньої енергосистеми.

**Відкрити:** https://ostapfed.github.io/deye-control-pwa/

- Сценарії: світло є, відключення, низький заряд.
- Відлік до планового вимкнення та ввімкнення.
- Демопоказники інвертора, генерації, навантаження й батареї.
- Оцінка залишку заряду, тестові налаштування у браузері.
- Приклад CSV та Telegram-повідомлення.
- Встановлення PWA; офлайн після першого успішного завантаження.

**Усі дані синтетичні. Додаток не з’єднується з інвертором, не отримує реальних графіків і не надсилає повідомлень Telegram.** Адреса є локальною назвою об’єкта; група автоматично не визначається. Налаштування зберігаються тільки у вашому браузері.

## Встановлення на телефон

Відкрийте посилання у Safari або Chrome, за потреби поза вбудованим браузером месенджера.

- iPhone: «Поділитися → На початковий екран».
- Android: «Встановити додаток» у панелі або меню браузера «Додати на головний екран / Встановити».

Можна користуватися як звичайною вебсторінкою без встановлення. Офлайн-кеш активується після першого відкриття та завершення реєстрації service worker.

## Розміщення та перевірка

GitHub Pages: гілка `main`, каталог `/`. Збірка та бібліотеки не потрібні. Ресурси, manifest scope/start_url/id та service worker використовують відносні шляхи для `/deye-control-pwa/`.

```bash
python3 -m http.server 8080
```

Локально: http://localhost:8080. Встановлення PWA поза localhost потребує HTTPS.

## Межі демо

Таймери використовують змодельований графік. Прогноз базується на сталому навантаженні, генерації 0.64 кВт і ККД 90%. Звіти ілюстративні. Для реального керування Deye потрібні локальний сервер та перевірений драйвер. GitHub Pages не запускає Python-бота й не підходить для зберігання його секретів.
