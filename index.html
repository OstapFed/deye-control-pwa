━ Генерація━ Споживання

«Сонце → будинок» — пряме живлення навантаження від генерації. Заряд батареї сюди не входить. Походження енергії, відданої батареєю, без окремого обліку не визначається.

Банк акумуляторів

Фізична ємність задається у кВт·год. Доступна частка у % коригує ємність у розрахунках, а мінімальний і цільовий SOC визначають межі заряду. Це різні параметри.

Ці налаштування використовуються для обліку та прогнозу. Для зміни реальних меж SOC в інверторі скористайтеся вкладкою «Інвертор» і перевіреним профілем.

Керування інвертором

Лише дозволені сервером параметри. Реальний запис підтверджується повторним читанням регістра; спроба та результат зберігаються в журналі.

Поточні налаштування інвертора

Читання не змінює налаштувань. Натисніть параметр, щоб змінити його.

⚠ — сервісні параметри (напруги батареї, захист мережі, тип BMS, ON/OFF). Неправильне значення може вимкнути інвертор, пошкодити батарею або порушити вимоги мережі; їх зміна вимагає введення «ТАК».

Підключення та об’єкт
GitHub Pages не підключається до інвертора напряму. Потрібен сервер із каталогу gateway та HTTPS або VPN із HTTPS.На комп’ютері панель відкривається ярликом DEYE Control без пароля. На телефоні пароль вводиться один раз — далі діє захищена сесія.
Telegram-бот
Підключіть реальний сервер, щоб налаштувати бота.
Як створити бота (2 хвилини)
1. У Telegram відкрийте @BotFather → /newbot, задайте назву та ім’я, що закінчується на bot.
2. Скопіюйте токен вигляду 123456789:AA… і вставте нижче.
3. Натисніть «Підключити мій Telegram» і відкрийте посилання — бот одразу надасть доступ.
Бот надсилає: зникнення й повернення світла, попередження перед плановим відключенням із прогнозом заряду на момент ввімкнення, досягнення резерву, втрату зв’язку та щоденний звіт. Команди: /status, /report, /week, /schedule, /settings, /set.
Профіль підключення до інвертора на сервері
Лише для перевіреної карти регістрів конкретної моделі й прошивки. Підтримано Modbus TCP та Solarman V5 через pysolarmanv5. Потрібні Python-залежності на сервері й SN логера. Хмарний API не підключено; регістри 16-бітні.
Профіль обирається за моделлю, яку визначив скрипт встановлення: SG04LP3 (трифазний) або SG0xLP1 (однофазний); карта регістрів спільноти ha-solarman. Після застосування запис залишається вимкненим: звірте показники з дисплеєм інвертора, потім позначте обидва прапорці нижче.
Домогосподарства та пошук інверторів
Пошук виконує підключений сервер у доступній йому локальній мережі або VPN. Для віддалених об’єктів потрібен мережевий доступ. Вибір перемикає активну панель для клієнтів сервера. Збір історії решти налаштованих об’єктів продовжується у фоні.
Додавання адреси не дозволяє запис автоматично. Для кожного об’єкта потрібно перевірити карту регістрів і параметри батарей.
Графік відключень
Адреса зберігає назву об’єкта. Автовизначення оператора/групи за адресою поки немає. Для реального відліку вкажіть графік своєї групи.
