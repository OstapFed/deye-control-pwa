━ Генерація━ Споживання

«Сонце → будинок» — пряме живлення навантаження від генерації. Заряд батареї сюди не входить. Походження енергії, відданої батареєю, без окремого обліку не визначається.

Банк акумуляторів

Фізична ємність задається у кВт·год. Доступна частка у % коригує ємність у розрахунках, а мінімальний і цільовий SOC визначають межі заряду. Це різні параметри.

Ці налаштування використовуються для обліку та прогнозу. Для зміни реальних меж SOC в інверторі скористайтеся вкладкою «Інвертор» і перевіреним профілем.

Керування інвертором

Лише дозволені сервером параметри. Реальний запис підтверджується повторним читанням регістра; спроба та результат зберігаються в журналі.

Підключення та об’єкт
GitHub Pages не підключається до інвертора напряму. Потрібен сервер із каталогу gateway та HTTPS або VPN із HTTPS.Пароль залишається в пам’яті вкладки. Після перезавантаження введіть його знову.
Профіль підключення до інвертора на сервері
Лише для перевіреної карти регістрів конкретної моделі й прошивки. Solarman V5 та хмарний API потребують окремого драйвера; тут підтримано стандартний Modbus TCP, 16-бітні регістри.
Домогосподарства та пошук інверторів
Пошук виконує підключений сервер у доступній йому локальній мережі або VPN. Для віддалених об’єктів потрібен мережевий доступ. Вибір перемикає активну панель для клієнтів сервера. Збір історії решти налаштованих об’єктів продовжується у фоні.
Додавання адреси не дозволяє запис автоматично. Для кожного об’єкта потрібно перевірити карту регістрів і параметри батарей.
Графік відключень
Адреса зберігає назву об’єкта. Автовизначення оператора/групи за адресою поки немає. Для реального відліку вкажіть графік своєї групи.
